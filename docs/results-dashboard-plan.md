# 可视化结果数据看板实施计划

## 一、目标与数据约定

- 实现一个零第三方依赖的轻量 Web 看板，以 `output/20260804_1513_wan22_ltable` 为默认结果目录，并允许命令行切换到其他同格式目录。
- 每条样本严格占一行，按“任务 ID、提示词、初始帧、Step 0 视频、Step 1 视频……”排列。
- 以 `run.json` 的样本列表为首选顺序，缺失时回退到 `samples/` 中按任务 ID 排序；Step 列从实际目录动态发现。
- 每页默认显示 5 条，可通过启动参数设置初始值，也可在页面中即时修改。

## 二、实现方案

- 新增基于 Python 标准库的 HTTP 服务和原生 HTML/CSS/JavaScript 前端，不增加项目依赖。
- 启动入口提供 `--result-dir`、`--page-size`、`--host` 和 `--port` 参数。
- 后端提供运行概览、分页样本数据和受限媒体访问接口；媒体路径必须位于结果目录内，并支持 MP4 Range 请求。
- 浏览器仅挂载当前页媒体，避免一次加载全部样本视频。
- 缺少提示词、初始帧或 Step 视频时显示占位状态，不阻断其他样本展示。

## 三、界面与交互

- 采用高对比度宽屏数据表，任务 ID、提示词和初始帧为粘性列，Step 区域支持横向滚动。
- 字体尽可能大且粗，媒体保持统一比例；使用清晰的表头、边框、圆角和层级配色。
- 视频使用 `autoplay`、`muted`、`loop`、`playsinline` 并保留控制条。
- 支持 A/D 和左右方向键翻页；输入框或媒体控件聚焦时不抢占按键。
- 提供上一页、下一页、页码、总样本数和每页数量控件。

## 四、接口与兼容性

- 不改变现有推理流程、结果目录或模型接口。
- 不展示与最后一步重复的 `output/video.mp4`，也不加载逐帧 PNG、overview 图和运行日志。
- 默认监听 `0.0.0.0`，便于远程服务器访问；端口可配置。
- 不使用 CDN，保证离线节点可运行。

## 五、测试与验收

- 单元测试覆盖结果解析、样本排序、动态 Step、分页边界、参数校验、缺失媒体和路径穿越防护。
- HTTP 测试覆盖首页、分页接口、图片、完整视频和 Range 响应。
- 使用真实 1000 条样本目录完成冒烟测试，验证首尾页和默认每页 5 条。
- 执行 Python 编译检查、自动化测试、服务启动检查和 `git diff --check`。
